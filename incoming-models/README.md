# 📥 Drop Downloaded Model ZIPs Here

Upload the `.zip` files you downloaded from Sketchfab into **this folder**
(don't unzip them — just drag the ZIPs in as-is).

Full model list + instructions: see **[../DOWNLOAD_MODELS.md](../DOWNLOAD_MODELS.md)**

After uploading, tell the agent **"models uploaded"** and it will extract,
inspect, compress and organize everything into `public/models/` automatically.
